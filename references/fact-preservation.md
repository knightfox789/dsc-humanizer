# Fact Preservation

## Locked information

Treat the following as immutable unless the user explicitly asks to correct them:

- names;
- organizations;
- project titles;
- village, block, district, state, and country names;
- dates and periods;
- numbers and percentages;
- financial figures;
- units;
- area;
- yield;
- crop names;
- target values;
- baseline values;
- assessment-year values;
- formulas;
- indicators;
- technical terminology;
- quotes and attribution.

## Never infer missing evidence

Do not convert:
- an activity into an outcome;
- an output into an impact;
- an association into causation;
- an observation into a universal conclusion;
- a small sample into a project-wide claim.

## Safe stylistic changes

Allowed:
- sentence reordering;
- grammar correction;
- removal of repetition;
- changing passive to active voice;
- clearer verbs;
- shorter phrasing;
- improved paragraph flow.

Not allowed without source support:
- adding reasons;
- adding outcomes;
- claiming behaviour change;
- claiming sustainability;
- adding farmer quotations;
- inventing before/after comparisons;
- strengthening uncertain language into certainty.
