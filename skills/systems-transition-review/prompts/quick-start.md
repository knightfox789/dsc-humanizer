# Systems Transition Review — Quick Start

## Full pilot-to-scale review

```text
Use the systems-transition-review skill.

Review this pilot/programme for scale readiness.
Do not assume that successful pilot results establish scalability.
Classify the scaling pathway, map the current and desired system states, identify necessary conditions, separate external changes from programme additionality, identify the rate-limiting constraint, test institutional ownership and resource realism, and give a GREEN / AMBER / RED / GREY scale-readiness verdict.

Input:
[paste concept note, proposal, pilot report or strategy]
```

## Short management review

```text
Use the systems-transition-review skill.

Give me a concise scale-readiness review:
- intended scale;
- dominant scaling pathway;
- what the pilot has actually demonstrated;
- main unresolved scale mechanism;
- rate-limiting condition;
- institutional owner / recurring financer;
- verdict;
- next 3 decisions.

Input:
[paste note]
```

## Water / groundwater programme

```text
Use the systems-transition-review skill.

Review this water-security or groundwater programme for scale readiness.
Check whether the relevant system boundary is administrative, hydrological, institutional or hybrid. Distinguish infrastructure replication, individual behaviour change and collective governance. Test incentives, market/policy conditions, O&M, monitoring, recurring finance, institutional ownership and trust/rule-setting where relevant.

Input:
[paste programme design]
```

## Agriculture / natural farming programme

```text
Use the systems-transition-review skill.

Review this agriculture or natural-farming programme.
Do not assume training is sufficient for adoption. Test income, cost, labour, risk, input supply, markets, procurement, policy, extension, finance and biophysical feasibility. Identify which conditions are necessary, which are enabling, and which condition is rate-limiting.

Input:
[paste programme design]
```

## Collective-action programme

```text
Use the systems-transition-review skill.

Review this collective-action programme for scale readiness.
Focus on trust, incentives to cooperate/free-ride, legitimacy, rules, enforcement, conflict resolution, facilitation capacity, time and transaction costs. Test whether the design has enough distributed negotiation/facilitation capacity to run local processes in parallel at the intended scale.

Input:
[paste programme design]
```

## Scale claim audit

```text
Use the systems-transition-review skill.

Audit every use of these claims in the draft: scalable, sustainable at scale, institutionalised, replicated, system change, state-wide adoption, government uptake.
For each claim, state:
1. evidence supporting it;
2. missing mechanism or condition;
3. whether the wording should remain, be qualified, or be removed.

[paste text]
```
