## Practical acceptance scenarios
1. Prior edition date missing: disclose seven-day assumption; do not infer date from poster metadata.
2. Ten consequential verified developments: state shortfall, never invent two additional stories.
3. Old atlas uploaded this week: distinguish upload date and underlying data date.
4. Several media copies of one release: count one development.
5. Logo unavailable: deliver text and request approved asset; never generate a replacement logo.
6. Poster generated at 1672×941: report actual dimensions, not requested dimensions.
7. User says "now write up" after a cover: deliver complete article from current research, not another cover.
8. User supplies an earlier edition: preserve voice and advance argument, reverify any reused factual claims.
9. A warning expires during preparation: refresh it or describe historically with explicit validity.
10. GitHub skill saved: provide its URL and explicit new-chat loading prompt; do not claim automatic installation.
