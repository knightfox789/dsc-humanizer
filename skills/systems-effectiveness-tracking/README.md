# DSC Systems Effectiveness Tracking

A reusable review and design skill for programme effectiveness, MEL, organisational health and systems-change measurement.

Use it when the question is not simply whether activities were completed, but whether resources were used well, the intervention worked, and the wider system is actually improving.

## Core distinction

The skill separates four layers:

1. **Organisational health** — is the organisation safe and credible to invest in?
2. **Programme efficiency and delivery** — is the programme using resources reasonably and producing agreed work?
3. **Intervention effectiveness / MEL** — did the intervention produce the intended outcome under the tested conditions?
4. **External system / landscape condition** — is the wider social, ecological or resource system measurably improving?

These layers should not be merged into one dashboard or one claim without a clear reason.

## Key safeguards

- Start with the stakeholder question and decision.
- Map every indicator to input/activity/output/outcome/impact/system condition.
- Match the monitoring period to the mechanism and season.
- Match spatial scale to the expected effect.
- Use continuous/repeated monitoring where snapshots would miss dynamics.
- Check rebound, displacement and trade-offs.
- Treat cost per output as context-sensitive unless real benchmarks exist.
- Define leverage attribution before claiming that funding was unlocked.
- Use SROI selectively, with transparent valuation and attribution assumptions.
- Treat data collection, cleaning, storage, privacy, analysis and archiving as part of the monitoring system.

## Water / NRM use

The skill is especially useful for water programmes where:
- results differ in wet and dry years;
- farm-level benefits may not aggregate to watershed or aquifer improvement;
- continuous hydrologic monitoring is needed;
- efficiency gains may increase total use;
- different dimensions of water security can trade off.

## Quick invocation

```text
Use systems-effectiveness-tracking.
Review this MEL / effectiveness framework. Separate organisational health, programme efficiency, intervention effectiveness and external system condition. Check indicator level, time and spatial scale, continuous-monitoring needs, unintended consequences, attribution, cost/leverage/SROI logic and data-system readiness. Give GREEN/AMBER/RED/GREY and priority improvements.
```
