# Systems Effectiveness Tracking prompts

## Full MEL / effectiveness review

```text
Use systems-effectiveness-tracking.

Review the attached monitoring, evaluation or performance framework.
Separate:
1. organisational health,
2. programme efficiency/delivery,
3. intervention effectiveness,
4. external system/landscape condition.

For each important indicator, check:
- stakeholder question and decision;
- results-chain level;
- numerator/denominator;
- geography and unit of analysis;
- timing/season;
- data source and owner;
- quality checks;
- attribution/contribution boundary;
- interpretation limitation;
- action triggered.

Also review continuous-monitoring needs, unintended consequences, cost/leverage/SROI logic and data-system readiness.
Give GREEN / AMBER / RED / GREY and 3–7 priority improvements.
```

## Water-security MEL review

```text
Use systems-effectiveness-tracking for a water-security programme.

Check whether the framework distinguishes:
- rainfall, recharge, storage, groundwater level, abstraction, allocation and reliable service;
- farm/plot outcomes from village, aquifer, watershed or canal-command outcomes;
- wet-year and dry-year performance;
- intervention efficacy from landscape-level water security;
- estimated water saving from observed system response.

Assess whether seasonal/continuous monitoring is required and whether rebound, redistribution, governance and ecosystem effects are covered.
```

## Indicator framework design

```text
Use systems-effectiveness-tracking.

Design an indicator framework from the decision questions outward, not from a pre-existing list of metrics.
Return a matrix with:
- stakeholder / decision question;
- result level;
- indicator;
- calculation / numerator / denominator;
- unit of analysis;
- geography;
- frequency / season;
- source;
- owner;
- data-quality check;
- interpretation limit;
- management action triggered.

Avoid redundant indicators and do not invent data sources that do not exist.
```

## Cost and value-for-money review

```text
Use systems-effectiveness-tracking.

Review proposed cost-per-output, funding-leverage and SROI indicators.
Check denominator stability, allocation logic, benchmark availability, complexity/novelty differences, attribution, deadweight, displacement, time horizon and uncertainty.
Do not invent peer benchmarks or monetised benefits.
```

## Systems-change progress tracking

```text
Use systems-transition-review first to identify what must change in the system and the rate-limiting conditions.
Then use systems-effectiveness-tracking to define how each critical condition will be observed over time.

Separate:
- programme-controlled indicators;
- programme-influenced indicators;
- wider system indicators that are monitored but not attributable to the programme.
```

## Organisational / Board dashboard review

```text
Use systems-effectiveness-tracking.

Review this management or Governing Board dashboard.
Check whether it mixes organisational health, programme efficiency and external impact in misleading ways.
Identify which indicators answer:
- Is the organisation healthy?
- Is each programme worth continuing/investing in?
- Did the intervention work?
- Is the external system improving?

Recommend a cleaner decision-oriented dashboard structure.
```
