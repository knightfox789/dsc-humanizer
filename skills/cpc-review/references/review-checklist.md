# CPC Review Checklist

Use this checklist with `skills/cpc-review/SKILL.md`.

## 1. Requirement and approval

- [ ] Requirement clearly defined
- [ ] Quantity reconciled across requisition, RFQ, quotation and comparative
- [ ] Unit / pack size / litre / kg / number / set consistent
- [ ] Approved budget / procurement plan available or status stated
- [ ] Competent approval available or gap identified
- [ ] No unexplained post-approval scope change

## 2. Specification and scope

- [ ] Same specification issued to all vendors
- [ ] Full scope comparable across vendors
- [ ] Brand restrictions justified where present
- [ ] Warranty specified where relevant
- [ ] Delivery specified
- [ ] Transport / freight clarified
- [ ] Installation / testing / commissioning clarified
- [ ] Accessories / consumables clarified
- [ ] Expert validation obtained or recommended where technically specialised

## 3. Quotation integrity

- [ ] All quotations read from source
- [ ] Vendor identities clear
- [ ] Dates and validity checked
- [ ] Full scope quoted
- [ ] Conditions / exclusions identified
- [ ] Revised rates supported in writing
- [ ] Unusual similarities flagged only as concerns, not allegations

## 4. Independent arithmetic

For each vendor verify:

- [ ] Quantity × unit rate
- [ ] Subtotal
- [ ] GST / tax
- [ ] Freight / transport
- [ ] Installation
- [ ] Other charges
- [ ] Discount
- [ ] Final landed / turnkey total

## 5. Source quotation vs comparative statement

For every material item:

- [ ] Unit rate matches
- [ ] Quantity matches
- [ ] GST matches
- [ ] Freight matches
- [ ] Installation matches
- [ ] Discount matches
- [ ] Negotiated rate has written support
- [ ] Total matches independent calculation

## 6. Responsiveness

Classify each vendor:

- **Responsive**
- **Responsive subject to clarification**
- **Non-responsive / incomplete**

Record the reason for any non-responsive classification.

## 7. L1 determination

- [ ] Numerical L1 identified
- [ ] Responsive L1 identified separately
- [ ] Package-wise vs item-wise basis justified
- [ ] Omitted items tested for ranking impact
- [ ] Negotiated rates tested for ranking impact
- [ ] Changed scope recalculated
- [ ] L1 status stated: Verified / Provisionally verified / Not verified

## 8. Price reasonableness

Check available evidence:

- [ ] Other responsive quotes
- [ ] Previous purchase rate
- [ ] Approved budget
- [ ] Market survey
- [ ] Benchmark / catalogue / e-marketplace evidence
- [ ] Independent price-discovery document

Remember: **lowest price does not by itself prove reasonable price.**

## 9. Commercial terms

- [ ] Payment terms
- [ ] Advance payment
- [ ] Delivery period
- [ ] Warranty
- [ ] After-sales support
- [ ] Validity
- [ ] Transportation
- [ ] Installation
- [ ] Taxes
- [ ] Retention / security where applicable

## 10. Vendor eligibility

Where applicable:

- [ ] GST
- [ ] PAN
- [ ] Shop Act / establishment registration
- [ ] MSME / Udyam
- [ ] Authorised dealership
- [ ] Experience
- [ ] Licence / certification
- [ ] Bank details

Identify which are mandatory and which are informational.

## 11. Red-flag scan

- [ ] Quantity mismatch
- [ ] Pack / unit confusion
- [ ] Unsupported negotiated rate
- [ ] Comparative differs from quotation
- [ ] Incomplete quote treated as L1
- [ ] Restrictive specification
- [ ] Unexplained price gap
- [ ] Missing material dates / signatures
- [ ] Post-quotation changes
- [ ] High prices across all vendors
- [ ] Large advance
- [ ] Missing warranty / service
- [ ] Scope changed after quotation
- [ ] Procurement split without justification
- [ ] Single responsive bid with weak price benchmark

## 12. Verdict gate

### GREEN
All material verification is complete; responsive L1 is verified; price is reasonably supported; no material gap remains.

### AMBER
Procurement is supportable but specific correctable conditions must be completed before PO / Work Order.

### RED
Critical verification fails or cannot be completed; L1 is wrong/unsupported; material technical or competition problem exists; or fresh price discovery / re-bid is required.

## 13. Final output check

Before finalising, confirm the response contains:

- [ ] Executive summary
- [ ] Document / gap check
- [ ] Vendor-wise L1 verification
- [ ] Material CPC observations
- [ ] GREEN / AMBER / RED verdict
- [ ] Actionable recommendation
- [ ] Short CPC observation for Purchase Note / minutes
- [ ] Email draft only if requested
