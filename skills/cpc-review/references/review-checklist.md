# DSC CPC Review Checklist

Use this checklist for CPC reviews across all DSC project states, units, programmes and funding partners.

## 1. Context identification

Record where available:
- State
- DSC unit / district / project
- Funding partner / donor
- Procurement category
- Item / service / work
- Approved or estimated value
- Approval route / delegated authority
- Applicable project / donor / DSC procurement condition

Do not assume a rule merely because it applied in another state or project.

## 2. Document map

Check availability of:
- Forwarding / approval email
- Purchase Note / Purchase Requisition
- Approved budget / procurement plan
- Applicable procurement SOP / donor condition, where relevant
- RFQ / enquiry
- Technical specification / BoQ / scope
- All vendor quotations
- Comparative statement
- Purchase committee minutes / negotiation note
- Vendor eligibility documents, where applicable
- Previous purchase rate / benchmark / price-discovery record
- Technical expert note / site assessment, where relevant
- Draft PO / Work Order, if available

Classify each missing item as:
- Critical
- Material but correctable
- Informational

## 3. Requirement reconciliation

Verify across requisition, RFQ, quotations and comparison:
- Item description
- Quantity
- Unit
- Pack size
- Technical specification
- Delivery location
- Installation requirement
- Accessories / consumables
- Testing / commissioning
- Warranty / service requirement
- Scope additions or deletions

Flag any mismatch.

## 4. Approval and budget

Check:
- Budget / procurement plan availability
- Approved quantity and estimated cost
- Evidence of required approval
- Correct project / unit / state reference
- Correct funding source
- Any applicable donor condition evidenced in the file

If the applicable authority or threshold cannot be verified from the available documents, state `not verified` rather than assuming it.

## 5. Quotation process

For each quotation check:
- Vendor name and identity
- Date
- Validity
- Full scope quoted
- Technical specification
- Quantity and unit
- Tax basis
- Freight / transport
- Installation
- Other charges
- Discount
- Payment terms
- Delivery period
- Warranty / service
- Signature / authenticity indicators where expected
- Any revision / negotiation and its written support

Review chronology and unusual similarities between quotations.

## 6. Independent arithmetic

For each vendor recalculate:

`Quantity × Unit Rate = Line Total`

Then add or deduct as applicable:
- GST / taxes
- Freight
- Loading / unloading
- Installation
- Testing / commissioning
- Accessories
- Other charges
- Discount

Calculate the final landed / turnkey / evaluated cost.

Do not compare tax-exclusive and tax-inclusive figures without normalising them.

## 7. Source quotation vs comparative statement

Cross-check every material field:
- Rate
- Quantity
- Tax
- Freight
- Installation
- Discount
- Final total
- Payment terms
- Delivery
- Warranty
- Validity
- Scope inclusions / exclusions

Any unexplained mismatch must be reported.

## 8. Responsiveness

Classify each bid:
- Responsive
- Responsive subject to clarification
- Non-responsive / incomplete

Consider both technical and commercial requirements.

A cheaper incomplete quotation is not responsive L1.

## 9. L1 determination

Record both:
- Numerical L1
- Responsive L1

Check whether award is:
- Package-wise
- Item-wise
- Lot-wise
- State-wise
- Centralised / multi-state

Only use an award basis that is permitted and operationally appropriate.

If the scope changes, recalculate all vendors on the same basis or recommend fresh quotations.

## 10. Price reasonableness

Assess separately from L1 using available evidence:
- Competing responsive quotations
- Previous DSC purchase rates
- Approved estimate / budget
- Market survey
- Published / catalogue / e-marketplace rates
- Technical / engineer estimate
- Recent comparable procurement
- Documented negotiation / price discovery

When comparing rates across states or districts, consider legitimate differences in:
- Freight
- Installation
- Local availability
- Quantity
- Specification
- Timing
- Service obligation

State:
- Reasonableness established
- Partially established
- Not established

## 11. Commercial terms

Compare:
- Advance payment
- Payment milestones
- Delivery period
- Warranty
- After-sales service
- Quote validity
- Freight
- Installation
- Retention / security / performance guarantee where applicable

Flag material commercial risk or unequal evaluation basis.

## 12. Vendor eligibility

Where applicable check:
- GST
- PAN
- Business / establishment registration
- MSME / Udyam
- Authorised dealership / OEM support
- Relevant experience
- Licences / certifications
- Bank details
- Donor / project-specific eligibility

Do not treat an informational document as mandatory unless the applicable procurement process establishes that requirement.

## 13. Red flags

Check for:
- Requisition vs RFQ mismatch
- Pack / litre / kg / number confusion
- Unsupported negotiated rate
- Comparative statement mismatch
- Incomplete quote treated as L1
- Restrictive specification without justification
- Unexplained large price gap
- Missing dates / signatures where required
- Post-quotation scope change
- High prices across all vendors
- Large advance payment without basis
- Missing warranty / service terms
- Procurement splitting without justification
- Unequal evaluation basis
- Bidder-specific post-bid relaxation
- Project / state / donor identity inconsistency
- Applicable procurement requirement not evidenced

## 14. Verdict gate

### GREEN
Use only when responsive L1 is verified, price reasonableness is established on available evidence, comparison is fair, and no material unresolved gap remains.

### AMBER
Use when responsive L1 is likely correct but a correctable clarification/documentation point must be closed before PO / Work Order and is not expected to change selection.

### RED
Use when L1 cannot be reliably established, bids are not comparable, proposed vendor is materially non-responsive, price is not reasonably supported, critical evidence is missing, or fresh price discovery / quotations / re-tendering are required.

## 15. Re-review checklist

For each earlier observation mark:
- Closed
- Partially closed
- Open
- New issue identified

Then verify whether:
- L1 changed
- Price reasonableness changed
- Scope changed
- New commercial terms were introduced
- Verdict should change

## 16. Required final outputs

A full review should normally include:
1. Executive summary
2. Document completeness table
3. Vendor-wise L1 verification table
4. Price reasonableness assessment
5. Key CPC observations
6. GREEN / AMBER / RED verdict
7. Final CPC recommendation
8. Short CPC observation for Purchase Note / minutes
9. Reply email only if requested
