# CPC Review Quick-Start Prompts

## Full review

```text
Use the CPC review skill.
Read all uploaded procurement documents completely before giving any conclusion.

Give me:
1. Executive summary
2. Document gaps
3. Independent vendor-wise L1 verification
4. Material CPC observations
5. GREEN / AMBER / RED verdict
6. Final CPC recommendation
7. Short CPC observation for the Purchase Note / minutes

Do not assume missing facts. Distinguish numerical L1 from responsive L1, and L1 correctness from price reasonableness.
```

## Short review

```text
Use the CPC review skill. Read all documents first. Verify quantity, scope, technical responsiveness, arithmetic, source quotation vs comparative, commercial terms, price reasonableness and responsive L1. Flag gaps/red flags and give GREEN/AMBER/RED verdict, recommendation and CPC observation.
```

## Review plus response email

```text
Use the CPC review skill and complete the full review first.
Then draft a short, constructive reply email to the field/procurement team based only on the verified findings.
Use kaushal-voice for tone, but do not soften or change the CPC conclusion.
```

## Re-review after clarification

```text
Re-review this CPC proposal using the previous CPC findings plus the newly submitted clarification/documents.
State which earlier gaps are now closed, which remain open, whether responsive L1 changes, and whether the GREEN/AMBER/RED verdict should change.
Do not repeat resolved observations unless they still affect approval.
```

## Price reasonableness focus

```text
Use the CPC review skill with special focus on price reasonableness.
Separate:
- numerical L1;
- responsive L1;
- evidence that the responsive L1 is reasonably priced.
If benchmark evidence is insufficient, say so clearly and recommend the minimum additional price-discovery step needed.
```
