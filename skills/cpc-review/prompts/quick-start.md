# CPC Review — Quick Start Prompts

## 1. Full CPC review

```text
Use the CPC review skill.

Read all uploaded procurement documents completely before giving any conclusion.
Identify the state, DSC project/unit and funding partner where available.
Review independently from the DSC CPC perspective.

Verify:
- requirement, quantity, unit, pack size and scope;
- approval / budget trail;
- applicable donor/project procurement condition, where evidenced;
- specification comparability;
- all vendor quotations;
- technical and commercial responsiveness;
- arithmetic, GST, freight, installation and final landed cost;
- source quotation vs comparative statement;
- payment, delivery, warranty and service terms;
- written support for negotiated/revised rates;
- numerical L1 vs responsive L1;
- price reasonableness;
- missing documents and procurement red flags.

Give:
1. Executive summary
2. Document completeness/gaps
3. Vendor-wise L1 verification table
4. Price reasonableness assessment
5. Key CPC observations
6. GREEN / AMBER / RED verdict
7. Final CPC recommendation
8. Short CPC observation for Purchase Note/minutes

Do not assume missing facts.
```

## 2. Short CPC review

```text
Use the CPC review skill. Read all documents first. Identify the state/project context and independently verify specification, quantity, commercial terms, arithmetic, source quotation vs comparative statement, responsive L1 and price reasonableness. Flag material gaps/red flags and give GREEN/AMBER/RED verdict, recommendation and short CPC observation. Do not assume missing facts.
```

## 3. Re-review after field/project clarification

```text
Re-review this CPC proposal using the CPC review skill.

Compare the new clarification/documents with the previous CPC findings.
For every earlier observation mark:
- Closed
- Partially closed
- Open
- New issue identified

Recalculate responsive L1 if scope, rate, tax, freight, installation or other commercial terms changed.
Reassess price reasonableness if new benchmark evidence is provided.
State whether the previous GREEN / AMBER / RED verdict changes and why.
Give a revised CPC observation and final recommendation.
```

## 4. Multi-state / centralised procurement

```text
Use the CPC review skill for this multi-state DSC procurement.

Identify each delivery state/unit and verify whether specification, quantity, freight, installation, service obligations, taxes and landed cost differ by location.
Confirm whether award is intended centrally, state-wise, lot-wise or item-wise.
Determine responsive L1 on the permitted award basis and do not compare only headline unit rates where landed cost differs.
Give GREEN / AMBER / RED verdict and recommendation.
```

## 5. CPC reply email

```text
After completing the CPC review, draft a short, constructive and professional reply email to the project/procurement team. Mention only the material conditions that must be closed before approval. Do not dilute any RED or AMBER requirement.
```

## 6. Price-discovery-only review

```text
Use the CPC review skill only for price reasonableness.
Compare available quotations, previous DSC rates, approved estimate/budget and market/benchmark evidence. Account for legitimate differences in location, freight, quantity, specification, installation and timing. State whether price reasonableness is established, partially established or not established, and recommend approval, negotiation, fresh price discovery or re-bidding as appropriate.
```
