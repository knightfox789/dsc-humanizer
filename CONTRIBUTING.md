# Contributing

## What belongs in this repository

Changes should improve clarity, factual integrity, natural professional voice, or domain-aware editing behaviour.

## Core rule

**Style may change; facts must not.**

Do not introduce rules whose main purpose is to evade AI-detection systems. The skill is intended to improve authentic writing quality.

## Suggested workflow

1. Create a branch such as `improve/donor-report-voice`.
2. Update `SKILL.md` or the relevant reference file.
3. Add or revise at least one evaluation case.
4. Check that names, figures, dates, units, technical terms, and supported claims remain unchanged.
5. Update `CHANGELOG.md` when the change is user-visible.

## Versioning

- PATCH: wording fixes, examples, small rule improvements.
- MINOR: new writing mode, new domain reference, substantial workflow improvement.
- MAJOR: incompatible redesign of the skill interface or behaviour.
